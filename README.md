# Cockroach Fund Tree

A one-page dashboard of Piet Viljoen's Cockroach Fund (Merchant West SCI Worldwide Flexible Fund, RCGFA).

The fund is the trunk. Each holding branches off on the date Piet bought it, or first mentioned it in his RECM letters if it was already owned. A branch's thickness is the holding's share of the fund, and it changes where he adds or trims. Markers show buys, adds, trims and sales. Clicking a holding shows every time Piet wrote about it, with a link to the letter.

## What's in the repo

```
index.html                 the page
data.js, fund.js, prices.js  generated by the build script; don't edit by hand
scripts/fetch_prices.py    fetches total return prices in rand from Yahoo Finance
scripts/build_data.py      turns the CSV and JSON files below into the .js files
.github/workflows/         the weekly price update
data/trades/               one CSV per letter volume: every buy, add, trim, sale and size
data/positions/            holdings at the end of each volume (input for the next volume's run)
data/notes/                letters with nothing on the fund, unclear cases, other funds
data/fund/                 fund, benchmark and category growth from the Merchant West factsheet
data/prices/               total return in rand, one file per ticker (written by the weekly Action)
```

## Put it online with GitHub Pages

1. Create a new repository on GitHub and upload everything in this folder (keep the folder structure).
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick `main` and `/ (root)`, and save.
4. After a minute the page is live at `https://<your-username>.github.io/<repo-name>/`.

You can also open `index.html` straight from your computer; it needs no server.

## Update it

You need Python 3 for these steps. Run the commands from the repository folder.

**After a new letter volume.** Run the `cockroach-fund-trades` skill on the volume, save the trades CSV as `data/trades/cockroach_trades_v5.csv` (and the positions and notes files in their folders) and upload it. The GitHub Action fetches prices for any new tickers and rebuilds the page.

**New factsheet.** Replace `data/fund/merchant_west_fund_data.json` with the new one (same layout) and run the build script.

**Prices.** Every Friday at 19:00 (and whenever the trades, fund data or scripts change) a GitHub Action runs `scripts/fetch_prices.py`, which downloads every holding's closes and dividends from Yahoo Finance and writes its **total return in rand** to `data/prices/<TICKER>.csv`: each dividend is reinvested on its ex-date and every week is converted at that week's exchange rate. Currency held as cash (e.g. `JPY=X`) follows its rand exchange rate. It then runs `scripts/build_data.py` and commits the result, and GitHub Pages republishes the page. You can also start it from the **Actions** tab with **Run workflow**.

A holding with no market price (the unlisted Merchant West funds, SA and Namibian government bonds, cash) is drawn flat with a dotted line and left out of the bucket returns. So is one whose Yahoo history starts after its first mention (Westaim's old ticker now belongs to another company, so Yahoo only has it from July 2026). For a holding Yahoo doesn't have at all, you can add a CSV by hand to `data/prices/`, named after its ticker, with `date,close` columns holding total return values in rand.

The fund line itself (the trunk) comes from the factsheet and is already a total return. The fund isn't on Yahoo, so replace `data/fund/merchant_west_fund_data.json` when a new factsheet comes out.

## Things to know

- **Sources.** Trades, sizes, dates and quotes come from the RECM letters (recm.co.za/letters), Vol 1 no 1 to Vol 4 no 35. The fund, benchmark and category lines come from the Merchant West minimum disclosure document as of 30 June 2026; the monthly values were read off its chart and are accurate to about ±0.3.
- **The letters start in Aug 2023**, three years after the Cockroach process began (Sept 2020). Holdings already owned by then start at their first mention.
- **Forever stocks.** Piet gives only a group size ("14% in 6 of my 10 Stocks, Forever"), so six of them are drawn at about 2% each and marked as estimates.
- **Gone without a reported sale.** Wheaton, Exor, Westaim, BAT, and the US$ and rand cash are missing from his September 2026 holdings list. They end with a "?". Edit the `GONE` list in `scripts/build_data.py` if a later letter explains them.
- **Russian shares** (four stocks, marked to zero) are still owned but not drawn.
